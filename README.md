# APD – Laborator

Proiect de laborator pentru disciplina Achiziția și prelucrarea datelor.
Nod de achiziție a temperaturii bazat pe ArduinoUno. 
Platformă: Arduino Uno R3 (ATmega328P)
Autor laborator: Mohammad Hossein Mohsenpour

## Parametri

- SENSOR_PIN: A0 – intrarea analogică a senzorului.
- SAMPLE_PERIOD_MS: 1000 ms – perioada de eșantionare.
- SERIAL_BAUD: 115200 – viteza comunicației seriale.
- LED_PIN: 13 – pinul LED-ului de stare.
- BUTTON_PIN: 2 – butonul de pornire/oprire a achiziției.
Comunicație serială la 115200 baud
Comunicație serială la 19200 baud
